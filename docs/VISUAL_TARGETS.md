## 2. 图与正式制作之间的边界

- 风格目标：温暖、干净、固定斜俯视、拟人双足猫狗，约3.5–4头身的比例提案；猫尖耳短吻、狗更长口鼻，装备在实际镜头能辨认。比例和风格仍待用户审阅。
- 实现以共用基础体、装备挂点、骨架动作、石／木／自然模块和简单材质为主；不把概念图中的细碎草木、流水或光效全部照搬进游戏。概念图不加入正式游戏包。
- 近战位在道路接敌处，远程位在合法射程内；独立工程便道必须连续且不穿越活跃狗线。静态图不能证明两接敌槽、侧绕、首领碰撞、射程或任务路径已合法，须在引擎中测量。
- 技能只用已有规则：鼓舞就是6秒攻击冷却加速，不加速施工、前摇或飞箭；分裂是弩Ⅲ被动分支；减速网是每战2次道具。光环、分裂箭或地面网的美术示意不能改变范围、伤害、触发和次数。
- 卡图价格用于对照规则：制造60／75／95；盾升级追加50／80，弩Ⅱ追加60、弩Ⅲ两分支各追加110，投弹升级追加70／100；鼓舞每波1次，网每战2次免费。升级价不是完整新造总价。
- 图上的文字和卡面仍是栅格画面，正式UI需独立字体、面板、合法状态、取消／确认、触屏热区与安全区；不能将一张目录图直接当可交互界面。
- 3基础体、2骨架族、14动作类、13职业装备（含盾猫短木棒）＋1弩箭、≤18场景主要网格均是制作预算，39骨骼单位和128／64飞弹／纯FX池是压力候选，概念图不能证明预算或三端性能达标。

当前完成的是目标画面与制作指令细分。真实资产、动作、Cocos导入、手机操作、战斗通关和Windows／Android／抖音分别验收均未开始，具体门槛见[执行清单](EXECUTION_CHECKLIST.md)。
