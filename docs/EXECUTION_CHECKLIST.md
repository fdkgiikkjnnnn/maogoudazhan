## T2. 真实猫狗资产与动作样本

- [ ] 先一猫一轻狗基础体，保留Blender源文件及最小来源／使用条件记录；实际导入Cocos验证glTF／GLB。

- [ ] 骨架、轴向、脚底、肩肘、权重、尺度、挂点与材质正确；两个同类同时播放不同动作不串姿态。
- [ ] 样本实际运行并记录网格、材质、纹理与帧时；静态模型、概念图或可旋转角色页面不能当作动作通过。

通过标准：最易穿帮的基础体与动作可用于真实战斗；未通过先修样本，不并行量产五区和全部装备。

## T3. 施工、经济与唯一命令

- [ ] 制造只在准备／战斗合法接受时扣一次款、锁一次位；错误战位、已占用、资金不足、忙碌或非法阶段不扣钱。
- [ ] 工程猫一任务、不排队；忙时可看价格／射程／下一波；常驻目的地、前往／施工状态和剩余时长。
- [ ] 前往取消全额退款与解锁各一次，施工后取消拒绝；锁位禁止拆除、再次升级、切分支，不能借其他按钮绕过施工。
- [ ] 便道独立连续、不挡狗不受伤；路径目标≤18、移速6、施工1.5，单任务目标≤4.5模拟秒；不靠瞬移或阶段双移速。
- [ ] 盾倒地仍占位；完工才生成／更新属性；终局与完工同一步无幽灵单位。
- [ ] 非最终清波保留旧任务，进入收尾；结束／前往取消后才回净空准备并开放新命令和下一波。
- [ ] 盾Ⅱ／Ⅲ完工当前HP更新为480／720；升级／拆除只在准备；Ⅰ→Ⅱ→Ⅲ逐档支付，分支本局锁定；拆除向下取整返还总投入75%，不能双退款。

通过标准：快速重复点击、取消、锁位、清波与终局均有唯一任务和资金事件可解释，没有负余额、重复退款或隐形任务。

## T4. 做通1-1原三波战斗

- [ ] 盾只攻击所挡狗；远程按到水晶剩余实际路程再spawnId；换靶不返还冷却，空闲不积连击。
- [ ] 箭绑定目标与唯一ID，实际线段扫掠触达才伤害；目标先死、TTL、清波与终局正确消散／清理。

通过标准：规则日志能解释画面，覆盖多箭同目标、最后狗死亡／漏怪、终局施工、组间空场、暂停与重开边界。

## T8. 新系统、双入口与存档边界样本

- [ ] 投弹真实触达后至多4目标爆炸，目标先死无补炸，按爆心距离／ID排序，不重复伤害和击败奖。
- [ ] Ⅲ弩二选一：主箭命中后最多2不同低伤副箭，副目标同时在命中半径2和源弩射程5内，排除主目标、副箭不再分裂、真实触达才伤害；主失靶不裂，本次击败仍裂，终局当步不生成副箭；重弩忽略固定护甲。
- [ ] 减速网每小关2次、跨波保留余量；预览合法后才消耗，重叠不叠加，首领减速不同，清波／终局清地面效果。
- [ ] 普通／快／重装／头犬／首领规则与奖励／漏怪代价一致；头犬第三击、暂停、换盾和首领大代理验证。
- [ ] T2／T3双入口同一水晶；按剩余实际弧长排序、按全局ID破同值，不比较不同路线原始s。
- [ ] 首领固定支援表完全出生并清完才胜利，击杀首领不提前结算；首领可挡、绕行不穿人。
- [ ] 净空快照双槽保存／恢复覆盖异常中断、清波收尾、失败、主动弃局、换关、胜利与坏档；终态不能让旧槽复活。
- [ ] 存储写失败明确未保存；永久进度与检查点同一版本记录，既不承诺云恢复也不声称能抗故意杀进程。

通过标准：新机制和异常边界先在少量样本验证，再填20战；未通过的机制不批量传播到后11关。
