## 2. 可展开的完整波表

配方 O8S2 代表普通8、快狗2，合计10；各配方是一整波的两入口合计，不是每入口各发一次。每波最多30狗；本波未出生数和活狗数都为0才可清波，下一波必须手动开，不跨波叠敌。

除1-1和最终首领波外，确定出怪顺序用循环槽位 **O、O、S、A、E** 填满本波配方：依次尝试槽位，某类已用完就跳过且不占一个出生时间，继续直到全部数量用完。例如O8S2先得到O,O,S,O,O,S,O,O,O,O。没有随机种子或临时抽兵。首领不放进此循环。

三个出兵节奏：

- P0 原教学：4只一组，组内0.8秒，组末到下组首6秒。组g、组内j（从0开始）的出生时刻为g×8.4+j×0.8。1-1只用此节奏。
- P1 常规：4只一组，组内0.75秒，组末到下组首4秒；时刻g×6.25+j×0.75。默认所有波使用P1。
- P2 紧凑：4只一组，组内0.65秒，组末到下组首3秒；时刻g×4.95+j×0.65。只在下表列出的波采用。

全波首只t=0；最后一组不满4按实际数量截止。30只的P1末只44.5秒，P2末只35.3秒。组间空场不清波。

## 3. 资金候选核算与不能推导的结论

1-1完全保留v0.4：初始165；盾60＋弩75花135余30；全歼波1后84可再造弩75余9；全歼波2后69可造另一盾60余9。各波前累计可分配165／219／279。前两波累计漏3只可按此候选购齐，累计漏4则差3鱼干；不是每波可以漏3只。原三波对照和实测门槛仍要做。

新局内总价：盾Ⅱ110、盾Ⅲ190、弩Ⅱ135、任一弩Ⅲ245、投弹Ⅱ165、投弹Ⅲ265。每关不会预放猫或免费继承上一关等级。

可支付的候选开局不是唯一最优布阵：1-3盾Ⅰ60＋弩Ⅱ135=195≤200；1-4盾Ⅰ60＋弩Ⅰ75＋投弹Ⅰ95=230≤250；2-2两盾Ⅰ120＋弩Ⅱ135=255≤260；5-4盾Ⅲ190＋弩Ⅱ135=325≤380，或两盾Ⅰ120＋两弩Ⅰ150＋投弹Ⅰ95=365≤380。这些组合只证明初始买得起，无法证明守得住。

5-4最后一波前，假设前7波全歼，无拆除损耗，其击败收入分别48／60／61／75／82／102／115，合计543；清波7×30=210；累计可分配380+543+210=1133。候选终局混编“2盾Ⅲ＋2重弩Ⅲ＋1投弹Ⅱ”花380+490+165=1035，余98；没有要求8战位全Ⅲ。终波击败收入只能在终波中获得，不能拿它证明开波前采购。

关键输出对照（忽略前摇、飞行、选敌和溢伤）：弩Ⅰ30 DPS；弩Ⅱ45；分裂弩无护甲的1／2／3目标理论总DPS为45／60／75，其中三目标为(36+12+12)/0.8=75；重弩60单目标DPS。目标均有护甲8时，分裂1／2／3目标理论总DPS为35／40／45，其中三目标为(28+4+4)/0.8=45；弩Ⅱ35、重弩单目标60；投弹Ⅱ单目标约20.56、4目标约82.22。重弩对单重装更好、群狗时分裂／投弹更好是设计方向，必须用真实路径和时序核验，不能当成已测平衡。

## 4. 真实资产数量和压力预算

正式V1生产上限候选：

- 角色基础体3个：1猫体、1轻狗体、1重狗体。2套骨架族（猫／狗），两狗体共用骨架须实际验证；角色职责4猫、玩法犬种5种，不等于9套独立建模。
- 猫基础动作8类：待机、行走、施工、盾击、弩射、投弹、受击、倒地／退场；狗6类：待机、行走、普通攻击、重击、受击、退场。动作共14类，头犬／首领复用狗动作，不额外制作独立剧情演出。
- 职业装备12个主要网格：锤、工具箱、盾、猫头盔、基础弩、分裂弩附件、重弩、投弹包、投弹球、狗铠甲、头犬头饰、首领旗件。Ⅱ／Ⅲ盾和Ⅱ弩以共用材质／挂件显示，不再造每级完整猫体。弩箭1个额外网格；鼓舞／网优先用简单地面材质和UI，不新增骨骼角色。
- 场景共用模块目标≤18个主要网格，来自石材／木材／自然三组，包含路线直段／弯段／分合流、桥、墙、门、平台、仓库／营地件、低植被、水晶和战位标记。五主题靠组合和材质，20小关靠配置，不做20套新场景素材。美术小样不合格时先修基础体和持物动作，再量产。
- 常驻战斗猫最多8＋工程猫1＋当波最多30狗=39骨骼单位。活跃狗与退场动画中仍可见的狗合计占30狗池；开下一波前清理上一波退场角色与残留特效，不能让退场对象在新波上额外叠峰。30是两路总数，由波表保证，不是运行时静默延迟／删怪的性能限流。单波清完才下一波，因此没有两波同时常驻。该39上界由v0.5本次明确选定的波量和战位上限推导，不是沿用旧八波的实测结论，也不是全部渲染对象上界。首切片仍为12狗＋4战斗猫＋工程猫=17。
- 39单位压力还需覆盖分裂箭、投弹爆炸、1鼓舞和2网并存；初始设计把池分开：128个逻辑飞弹对象、64个纯表现特效对象，均是待实测目标预算。逻辑池满必须保留规则事件并采取安全扩容／备用对象，记录超预算供调整，绝不静默跳过箭、分裂或伤害；纯表现池可以按优先级省略非必要效果，但不得省略真实飞弹命中判定。

延续低至中面数真实3D、固定斜俯视、物种／职业装备可辨。3000–6000面角色、1024共享贴图／移动512、单主光与简化地面影仍是候选。抖音包体按v0.4已核的普通构建限制保留主包内部3.5MB／总包18MB目标；三组模块与新增轻狗／重狗的实际总资源要重新测，不因分包而假定突破总包限制。Windows、Android、抖音分别构建、分别记录工具版本、包体、首载、设备、P95帧时和内存，不以Web预览代验。

## 5. 配置与资产维护边界

关卡数据全部复用主方案的同一战斗执行器；主题、拓扑、战位和波表可配置，不复制20套战斗逻辑。每区只增加必要材质／标牌和布局组合，角色与动作不按关卡复制。技术验证先做一猫一狗、1-1三波，再验证双路／分支／网和首领样本，基础体或持物动作未通过时先修样本，不同时量产五区。

当前4张v0.4概念图只覆盖教学桥视觉提案，仍待用户审阅；它们不是五区地图、正式游戏资产或实机效果的完成证据。
