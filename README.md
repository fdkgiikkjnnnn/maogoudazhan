## 第一版要做成什么

一张桥地图，一颗需要守住的水晶；拟人双足的工程猫、盾猫、弩猫和普通狗；2 个近战位、2 个远程位；8／10／12 只普通狗组成的 3 波；制造、施工、实际命中、漏怪、胜负、暂停和重开形成完整闭环。

首次正式试玩要有能看清动作的真实猫狗模型。白模可以帮助验证规则，但不能替代最终的完整猫狗试玩。

## 这次的优先级

1. 首选 Three.js + TypeScript + GLB 实时 3D，用本机浏览器尽快做出完整切片；这只是当前制作路线，不强制最终发布为 H5。
2. 3 波完整切片通过后，再决定 8 波扩展和最省事的可访问发布方式。
3. TapTap 账号入口、平台接入、原生安卓工具链不作为本地制作前置；现阶段不安装 Android Studio／SDK。
4. 商业化、广告收入、付费功能和平台资质调查后置。素材先保留最小来源／生成记录，公开发布前再确认适用使用条件。

本轮交付是方案入库。技术和数值是待实测的制作基线，预算算术不等于通关结果。开发状态以[执行清单](docs/EXECUTION_CHECKLIST.md)为准。
