# 猫狗大战塔防

第一版做成5个主题区域，每区4个小关（章节），共20场独立战斗、120波进攻。先从教学桥的3波技术样例打通，再做前三关12波体验，最后完成整套战役。

当前方案：**v0.5，2026-10-07修订**。本轮纸面一致性审计与数学复核已完成；仓库仍只有规划文档，游戏代码、真实猫狗／地图／动作资产、战斗模拟、性能与可玩构建均未开始。没有已上线版本，本轮不安装软件、不写游戏代码、不部署。

## 大关、小关和波怎么数

- 大关＝主题区域，共5个：石桥村口、木栈仓库、溪谷营地、城门大道、水晶庭院
- 小关（章节）＝一次独立战斗，每大关4场；进度第1／10／20关是第1／10／20场战斗
- 波＝这场战斗的一批进攻，每战3–8波，区域合计18／23／24／27／28波，总120波

1-1保留原桥地图、4战位、初始165鱼干和8／10／12普通狗。1-1至1-3共12波，加入快狗、局内Ⅱ级与鼓舞。它们是先验证的交付，不等于20战正式版完成。正式版还包含投弹猫、Ⅲ级、分裂弩／重弩、双入口、每战限2次减速网和首领总攻。

## 玩家怎么成长

每场从该关初始资金、空战位和Ⅰ级开始，用小鱼干制造并逐级升到Ⅱ／Ⅲ；弩Ⅲ在分裂与重弩间二选一。猫等级、余额与分支过关重置。首通永久开放后续关卡和横向功能，1星就能继续；不做账号等级、刷经验、无限数值养成或第二货币。

鼓舞每波1次、不能积攒，区域内攻击冷却加速6秒，工程施工不加速；减速网每战2次、跨波保留余量。三职业共用猫体与装备，五区域复用石／木／自然地面模块及三种路形，不为20关制作20套独立角色或地图。

## 多平台与当前进度

采用**Cocos Creator 3.8 LTS＋TypeScript＋真实实时3D**，Blender源资产与glTF／GLB交换，共用规则核心、Cocos表现层和PlatformAdapter：

- Windows原生版本 → Steam
- Android原生版本 → TapTap
- 抖音小游戏专用构建 → 抖音

同一源工程分别构建、分别测试。Mac日常制作不代表Windows原生验收；Windows＋Visual Studio环境后续另行准备。首领与两路合计每波≤30狗，8战斗猫＋工程猫推导39骨骼压力上界，飞弹／纯FX另设128／64候选池，全部待实测。

4张v0.4目标概念图仍待用户审阅；图是设计提案，不能代替真实资产、操作、性能或五区画面。当前纸面修订已处理末关资金、升级锁位、分裂命中时序、鼓舞冷却与异常续局边界；实际通关、职业价值、手机操作、包体和三端性能仍要按[执行清单](docs/EXECUTION_CHECKLIST.md)逐项验证。

开发、工具安装和部署后续获准再开始。商业化、广告、付费、平台账号／上传／商店审核和资质调查后置；规划完成不等于游戏完成或上线授权。
